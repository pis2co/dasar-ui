closable = false close-on-overlay = false close-on-escape = false

With closable="false" the default ✕ button is not rendered, so the dialog can only be closed from the action below.

Close

With close-on-overlay="false" clicking the backdrop no longer emits (onClose). The ✕ button and Esc still work.

With close-on-escape="false" pressing Esc no longer emits (onClose). The ✕ button and a backdrop click still work.
